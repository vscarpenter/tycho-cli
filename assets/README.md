# Brand assets

The tycho mark: a telescope/observatory with a terminal `>_` eye — a nod to the
astronomer Tycho Brahe. All four are exports of the same artwork at the sizes
each surface expects.

| File | Size | Used for |
|---|---|---|
| `tycho_banner_1280x640.png` | 1280×640 | README hero, and the **GitHub social preview** (see below). 2:1 is GitHub's exact spec. |
| `tycho_icon_512.png` | 512×512 | Full logo mark — README title, and any square-icon need. |
| `tycho_favicon_256.png` | 256×256 | Web favicon / app tile (no web surface ships today; kept for future docs pages). |
| `tycho_favicon_32.png` | 32×32 | Browser-tab favicon (same note as above). |

## Setting the GitHub social preview

This is a repository *setting*, not a file in the repo, so it can't be wired by
a commit:

**Settings → General → Social preview → Edit → upload
`assets/tycho_banner_1280x640.png`.**

It then appears when the repo is shared on social media, Slack, Discord, etc.
